Displaying the torch backend on the metrics dashboard — three candidate forms

Mockup for the port_plan section 4 design decision (display must not make the dashboard too busy). Data shown is representative, not measured. Each panel imitates one dashboard chart (wall time vs date for one cell/op). Pick a form (or a combination); the harness backend column then feeds it.

Option A — backend selector (one backend visible at a time)

backend:

Chart count unchanged; switching is a page-level control. Comparison requires flipping back and forth.

Option B — overlay (torch as a dashed series on the existing charts)

jax (solid) torch (dashed)

Direct visual comparison on every chart; doubles the series count everywhere (busier, especially on multi-device charts).

Option C — dedicated comparison view (ratio chart per cell/op)

torch / jax wall-time ratio the 2x gate

The existing pages stay exactly as they are (jax only); a new page shows torch/jax ratios against the gates. Cleanest separation; the absolute torch numbers live one click away.
